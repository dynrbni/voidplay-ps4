# Original concept artwork

All catalog entries remain fictional development fixtures. Artwork illustrates their identities;
it is not evidence of working applications, genuine screenshots, releases or compatibility.
Existing SVG assets are original project artwork. No proprietary Netflix/Overdrive artwork is used.

The V2 direction and raster artwork were generated with the built-in image generation tool on
2026-10-25. Final web assets are stored in `public/art/`; UI mockups are reference material only
and are not displayed as a flattened application interface.

## Prompt set

Shared constraints: original cinematic concept artwork, full bleed, sophisticated material and
lighting, no text, letters, logos, UI, watermark, existing game artwork or application screenshots.

- Homepage reference: black/white Voidplay console store, edge-to-edge orbital hero, quiet header,
  lower-left title/actions, a horizontal content shelf, generous TV-readable layout.
- Detail reference: selected item's landscape art and portrait cover, title/actions, open About and
  metadata columns, related concepts. No fabricated version, rating, release or screenshot.
- Orbit Workshop hero: tiny astronaut overlooking a dark basalt alien valley, huge rust-orange
  ringed gas giant and pale orbital station, charcoal/desaturated teal foreground, dark left third
  for separate UI text.
- Save Shelf: immense sculptural archive tower of stacked translucent jade and limestone slabs
  over a dark reflective sea, illuminated layers, quiet mist, architectural surrealism.
- File Desk: architectural canyon of sandstone panels and folded paper planes, tiny doorway,
  warm amber/cream, tactile material, cinematic desert landscape.
- Pixel Forge: isometric terracotta/cobalt ceramic cubes above dark water, warm windows,
  peach sunset, detailed sculptural voxel architecture.
- Local Player: concentric emerald-glass/silver circular portal above a still dark lake,
  distant green mountains, cinematic clouds and reflections.
- Signal Room: pale cyan sound-wave ribbons between slate mountain peaks over an ink-blue ocean,
  tiny lighthouse, dramatic light, editorial album-art dreamscape.

Delivery uses locally served WebP assets, with generated PNGs encoded to WebP without changing
composition. Manrope is locally served under `public/fonts/OFL-Manrope.txt`.
